How Script-Controlled ACL Works

01

Read Field Value

The script checks a selected field such as status, department or access level.

02

Apply Rule

JavaScript evaluates the field value against the defined access-control condition.

03

Control Access

The record is either allowed or restricted depending on the evaluated condition.
